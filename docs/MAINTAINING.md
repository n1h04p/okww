# n1h04p/okww 维护说明

这是基于 `ok-oldking/ok-wuthering-waves` 的个人维护分支，代码按 AGPL-3.0 继续发布。

## 当前适配基线

- 上游当前最新发布为 v3.8.1。
- 上游仓库在 2026-11-14 仍有提交，维护分支按上游最新提交同步。
- 当前最明确的 Windows 兼容问题是 Kuro 登录卡片作为独立顶层窗口运行时，旧版点击逻辑仍向游戏主窗口发送消息。上游 PR #1854 已针对这个问题提交修复。
- 1080p 窗口尺寸、登录页卡死、日常任务奖励流程和传送点重叠是优先回归范围。

## 维护流程

1. 先记录游戏版本、Windows 版本、分辨率、DPI、任务名称和日志。
2. 优先复现登录页、窗口识别、任务状态转换和奖励领取流程。
3. 运行仓库现有测试，再进行单个功能的实机验证。
4. 识别素材或坐标发生变化时，同时更新源文件和对应测试。
5. 每次同步上游时保留 AGPL 许可证、上游署名和本文件。

## 使用边界

这是第三方游戏自动化项目。使用可能违反游戏规则并造成账号处罚。发布前应阅读项目免责声明和 AGPL-3.0 条款。
